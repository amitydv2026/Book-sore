Simple Project: Book Store (Python + FastAPI)  
  
It has only 2 tiny services and about 6 files each.  
  
Book Service (MongoDB): add books, list books, keep stock count.  
Order Service (PostgreSQL): buy a book and see order history.  
Build it in 5 steps  
Book Service: write 3 endpoints: add book, list books, reduce stock.  
Order Service: write 2 endpoints: place order and get my orders. When an order is placed, it calls the Book Service to check and reduce stock.  
Add the design parts:  
A discount class (Strategy): NoDiscount, TenPercentDiscount.  
A payment maker (Factory): returns UPI or Card payment.  
Keep route, service and database code in separate files.  
Add the database parts:  
Wrap "save order + reduce stock" in one transaction.  
Add an index on user_id, run EXPLAIN before and after, and write down the time difference.  
Add the tools:  
A Dockerfile for each service and one docker-compose.yml.  
A Jenkins pipeline with 3 steps: install, run pytest, build the Docker image.
